# وحي (Wahy) — Quran Foundation Release

هذا هو **الإصدار الأساسي (Foundation / Pre-MVP Release)** من منصة وحي، مبني وفق
مواصفات الـ Golden Master Prompt (القسم 18، 221، 222). يغطي فقط الطبقة الأولى:
عرض المصحف كاملاً Offline. لا يغطي التجويد، التعرف الصوتي، أو القراءات العشر —
هذه تحتاج مراحل منفصلة موثقة في القسم 25 وما بعده.

## ما يتضمنه هذا الإصدار

- نص القرآن الكريم كاملاً (6236 آية، 114 سورة) — رواية حفص عن عاصم
- رسم عثماني (Uthmani script) مطابق هيكليًا لمصحف المدينة (طبعة 1405هـ)
- يعمل Offline بالكامل من أول تشغيل (لا اتصال إنترنت مطلوب أبدًا)
- تصفح حسب السورة، بحث نصي، عرض تفاصيل المصدر لكل آية
- بنية بيانات قابلة للتوسع لإضافة: تفسير، صوت، تجويد، قراءات لاحقًا

## مصدر البيانات والترخيص

- **المصدر:** Tanzil Project (نص Uthmani مُدقق يدويًا مقابل مصحف المدينة)
- **الرخصة:** Creative Commons Attribution 3.0 — استخدام حر في التطبيقات
  بشرط عدم التعديل وذكر المصدر
- **حالة التحقق الحالية:** تم التحقق الهيكلي فقط (عدد الآيات والسور مطابق
  للعدد المعتمد: 6236 آية). **لم تتم بعد** مراجعة علمية حرفية كاملة من
  متخصصين مقابل نسخة ورقية موثقة من مصحف المدينة — وهذه خطوة إلزامية
  (القسم 227-230) قبل أي اعتماد كإصدار إنتاجي نهائي.
- راجع شاشة "حول المصدر والتوثيق" داخل التطبيق لعرض هذه المعلومات للمستخدم.

## ⚠️ تنبيه مهم جدًا وصادق

**لم يتم بناء أو اختبار (compile/run) هذا الكود فعليًا** — بيئة العمل الحالية
لا تحتوي على Flutter SDK ولا اتصال بـ pub.dev (مستودع حزم Flutter)، لذلك لم
أتمكن من تشغيل `flutter pub get` أو `flutter build` أو `flutter test` هنا.

الكود مكتوب باحتراف ويتبع أنماط Flutter/Dart القياسية وواجهات الحزم المعروفة
(sqflite, path_provider, google_fonts)، لكن **يجب** أن يقوم مطور (أنت أو
إبراهيم) بما يلي قبل الوثوق به كإصدار جاهز:

1. تشغيل `flutter pub get` لتنزيل الاعتماديات
2. تشغيل `flutter analyze` لفحص الأخطاء الثابتة
3. تشغيل `flutter run` فعليًا على جهاز/محاكي والتحقق البصري
4. مراجعة توافق أسماء الخطوط في `google_fonts` (`GoogleFonts.amiriQuran`) —
   قد يحتاج تعديل حسب أحدث نسخة من الحزمة

## خطوات البناء (على جهازك)

```bash
# 1. تأكد من تثبيت Flutter SDK (3.3+)
flutter doctor

# 2. داخل مجلد المشروع
cd wahy_quran
flutter pub get

# 3. تشغيل على أندرويد (محاكي أو جهاز متصل)
flutter run

# 4. تشغيل على iOS (يتطلب Mac + Xcode)
flutter run -d ios

# 5. بناء نسخة إنتاجية
flutter build apk --release      # أندرويد
flutter build ios --release      # iOS (على Mac فقط)
```

## الخطوات التالية المقترحة (حسب مستند Golden Master)

1. **مراجعة علمية للنص** (القسم 227) — مقارنة حرفية بمصحف ورقي معتمد
2. **إضافة الصوت** — تلاوة مرتبطة بكل آية (يحتاج ترخيص ملفات صوتية)
3. **التفسير الميسر** — طبقة بيانات إضافية مع مصدر موثق
4. **محرك التجويد المرئي** (القسم 23) — يحتاج تصميم منفصل ومتخصصين
5. **توسعة القراءات العشر** (القسم 17) — نموذج بيانات معقد يحتاج علماء قراءات
